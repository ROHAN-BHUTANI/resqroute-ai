# 🚑 ResQRoute AI

AI-powered disaster response and emergency routing system.

## 🚀 Features
- AI Risk Prediction
- Emergency Route Optimization
- Real-time Dashboard
- Ambulance Tracking
- Disaster Simulation

## 🛠 Tech Stack
- Frontend: Next.js
- Backend: Flask
- AI: Python ML Model
- Maps: Leaflet

## ▶️ How to Run

### Backend
cd backend  
pip install -r requirements.txt  
python app.py  

### Frontend
cd frontend  
npm install  
npm run dev  

## 🎯 Impact
Reduces emergency response time using AI-driven routing and prediction.
